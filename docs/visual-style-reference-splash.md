# Visual Style Reference — HUD Loading Splash

Source: horizontal cyberpunk loading bar HUD (red → remapped to BFV yellow).

---

## 1. Core Aesthetic

- **Style name:** **Signal Load Bar**
- **Design philosophy:** Pure black field + one glowing progress bar + sparse mono labels. No map, no marketing copy column.
- **Key influences:** shooter / ops loading HUD · Build4 mono · brand yellow as the only glow

---

## 2. Color Palette

**Total: 3 colors**

| Color name | Hex / token | Usage |
|---|---|---|
| Pure black | `#000000` | Full overlay |
| Signal white | `#ffffff` | LOADING, analyze label, + glyphs |
| Brand yellow | `var(--primary)` / `#ffd83d` | Bar fill, %, corner brackets, thin accent lines |

---

## 3. Typography System

- **LOADING:** mono · uppercase · wide tracking · white · left of bar
- **Percentage:** mono black · large tabular · yellow glow · framed by hairline corners
- **Analyze / action:** mono · small · uppercase · white + muted

---

## 4. Key Design Elements

- Thick horizontal bar with soft yellow bloom
- End gap + tip segment near 100% (reference detail)
- Side glyphs: tick + `+` + hollow square
- Copy sequence while loading: Colombia → Venezuela · “look for help”
- Skip corner control

---

## 5. Visual Concept

Boot = acquiring the crisis signal before the map home unlocks.
